# 👗 Yoresora

**Yoresora** is a modern Android shopping application focused on women's fashion — especially dresses. It delivers a smooth, secure, and elegant shopping experience with integrated payment solutions, real-time notifications, and a scalable architecture.

---

## 🚀 Features

- Browse and purchase dresses with a beautiful UI built using **Jetpack Compose**
- Integrated **Eddahabia payment** via **Chargily Pay**
- Real-time push notifications with **Firebase**
- Smooth screen transitions using **Voyager Navigation**
- Secure backend built from scratch in **PHP & MySQL**
- Combined **MVVM + MVI** architecture for clean and scalable code
- Designed with future **Kotlin Multiplatform** support in mind

---

## 🔒 Payment Integration

Yoresora includes a full **payment workflow** using **Chargily Pay** connected to **Eddahabia cards**. This ensures secure and reliable transaction processing for Algerian users.

---

## ⚙️ Backend

- Custom backend API developed using **PHP**
- Database management via **MySQL**
- User authentication, product management, and order processing handled through secure endpoints

---

## 🧠 Architecture

The app follows **MVVM (Model-View-ViewModel)** combined with **MVI (Model-View-Intent)** to ensure a reactive, scalable, and testable structure.

- `ViewModel` handles business logic
- `StateFlow` updates the UI reactively
- Intent-based user actions improve maintainability and traceability
